7. Design-system feedback

  1. Define accessible text-bearing primary tokens instead of assuming the brand accent works for every CTA.
  2. Add finance-specific list, status, data-visualization, confirmation, permission, and export components with complete states.
  3. Publish semantic tokens for success, warning, error, informational, stale, partial, and privacy-sensitive states; retain text/icons so color is not the only signal.
  4. Publish platform breakpoints, type-scaling/reflow rules, localization stress cases, target sizes, focus styles, and reduced-motion behavior.
  5. Separate decorative staging tokens from product-library tokens and provide stable component/token names for handoff.
  6. Obtain design-system, brand, accessibility, product, engineering, privacy, and security review before treating this mapping as approved.
