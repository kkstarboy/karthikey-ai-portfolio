4. Study plan

  1. Confirm IA decision, scope, target contexts, locale/language, owner, consent, tool accessibility, and analysis plan.
  2. Pilot instructions and each card for clarity, neutrality, duplication, reading level, and keyboard/screen-reader access.
  3. Run the hybrid sort consistently; allow participant-created categories and capture rationale without leading.
  4. Analyze groupings and names by context; retain outliers and cross-listing needs.
  5. Produce a revised hierarchy with traceable changes and stakeholder risk review.
  6. Run a separate tree test with realistic findability tasks; do not reveal target labels in task wording.
  7. Record first click, path, success, directness, time/effort only with defined metrics, plus participant rationale.
  8. Revise and retest ambiguous or failed paths.

5. Analysis method

  • Card sort: item-by-item similarity, common groupings, category names, cross-listing, singleton/outlier cards, participant rationale, and segment/context differences. No agreement threshold is predeclared without method/sample review.
  • Tree test: task success, directness, first click, paths, backtracking, abandonment, time/effort if reliable, and qualitative rationale. Define partial/indirect success before analysis.
  • Preserve failed tasks, alternate groupings, minority/accessibility patterns, and conflicting expert/novice models.
  • Do not treat similarity as findability or tree success as comprehension.
  • Do not calculate percentages without a real denominator and study data.
